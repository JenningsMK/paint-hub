## Toolchain

This is a pnpm workspace monorepo driven entirely by the **Vite+** global CLI `vp` (not raw `pnpm`/`vite`/`vitest`). pnpm version and Node (>=22.18) are pinned in the root `package.json`. Vite+ docs are available locally at `node_modules/vite-plus/docs` (see `guide/` and `config/`).

- Imports of Vite/Vitest APIs must come from `vite-plus` (e.g. `import { defineConfig } from "vite-plus"`, `import { expect, test } from "vite-plus/test"`). The root lint config enforces this via the `vite-plus/prefer-vite-plus-imports` rule.
- Linting is type-aware with type checking enabled, so `vp check` also type-checks.
- A pre-commit hook (`.vite-hooks/pre-commit` → `vp staged`) runs `vp check --fix` on staged files.
- Shared dependency versions live in the `catalog:` in `pnpm-workspace.yaml`; `vite` is aliased to `@voidzero-dev/vite-plus-core`. Use `catalog:` for these in package manifests.

## Commands

Run from the repo root:

- `vp install` — install dependencies
- `vp run ready` — full validation: `vp check`, then all tests, then all builds
- `vp check` / `vp check --fix` — format (Oxfmt), lint (Oxlint), and type check
- `vp run -r test` — run tests in every package
- `vp run -r build` — build every package
- `vp run dev` — start the website dev server (`website#dev`)
- `vp run <pkg>#<script>` or `vp run --filter <pkg> <script>` — run a script in one package

Inside a package directory (e.g. `packages/ui-library`):

- `vp test` — run tests once (Vitest; not watch mode by default). `vp test watch` for watch mode
- `vp test tests/index.test.ts` / `vp test -t "<name>"` — run a single test file / test by name
- `vp pack` — build the library (tsdown); `vp pack --watch` for dev

## Structure

Workspace globs: `apps/*`, `packages/*`, `tools/*`.

- `apps/website` — Vite browser app (vanilla TS, currently the starter template). Build is `tsc && vp build`.
- `packages/ui-library` — publishable TS library built with `vp pack` (tsdown, `.d.ts` via tsgo) to `dist/index.mjs`; package `exports` are generated by the pack config. Tests live in `tests/` and import sources with explicit `.ts` extensions (`allowImportingTsExtensions`, `nodenext` resolution).

Each package has its own `vite.config.ts` for package-level `pack`/`lint`/`fmt` config; the root `vite.config.ts` holds workspace-wide lint, staged, and task-cache (`run.cache`) settings.
